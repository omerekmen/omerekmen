## Overview

A set of analyses across unrelated public datasets, each chosen to exercise a
different technique: regression for housing prices, K-means clustering for
customer segmentation, and classification for market trends.

## What I built

The full analysis for each dataset, with statistical hypothesis testing and
feature selection applied to keep the models interpretable rather than merely
accurate.

Early work from 2023, kept for the public repository. My current work is
